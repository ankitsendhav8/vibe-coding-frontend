The Workflow

How this entire project was built

01

Open Cursor

Start a new Angular project. Open the AI chat panel inside Cursor and set the context — project goal, preferred stack, folder structure.

02

Write the Prompt

Describe what you want in natural language. Be specific about design, responsiveness, component breakdown, and behaviour. The clearer the prompt, the cleaner the code.

03

Review & Iterate

Cursor generates the code. Review it, run it, and if something is off — re-prompt. No manual editing needed. Just better prompts.

Real Prompts Used

These prompts built this app

Not marketing copy. These are the actual prompts typed into Cursor to create VibeCoding.

Header

"Create a fixed header component with glassmorphism effect, a logo, nav links for Home, About Us, Terms and Conditions, a Get Started CTA, and a hamburger menu for mobile."

Backend

"Set up an Express.js backend with a users route, MS SQL Server connection, error handler middleware, and a not-found middleware."

Home Page

"Create a home page with a hero section, stats strip, features grid, how-it-works steps, and a CTA. Make it responsive and use a dark theme with indigo gradients."

Routing

"Set up Angular lazy-loaded routes for Home, About Us, and Terms and Conditions. Add page titles and a wildcard redirect to home."
