About This Project

Built by a developer.
Built by a prompt.

VibeCoding is a real, production-ready web application built entirely inside Cursor using AI prompt engineering. No scaffolding tools were hand-crafted. No component was written manually. Every line of code was generated from a clear, intentional prompt.

The Story

What happens when you treat prompts like code?

It started as an experiment: could a developer build an entire full-stack web application — Angular frontend, Node.js backend, SQL database, routing, components, styles — without writing a single line of code manually?

The answer, using Cursor and well-crafted prompts, was yes. VibeCoding is that experiment made real. Every route, every component, every API endpoint on this platform was described in natural language and brought to life by AI.

This isn't about being lazy. It's about being deliberate. Writing a good prompt requires you to think clearly about architecture, design, and user experience — arguably more than typing the code yourself.

Tools Used

The exact toolkit behind VibeCoding

No magic. Just these tools, used deliberately.

🖥️

Cursor

AI-native IDE. Every file in this project was generated from the Cursor chat panel. The entire codebase lives here.

🤖

Claude (Anthropic)

The AI model powering the code generation inside Cursor. Handles context, architecture, and edge cases exceptionally well.

🅰️

Angular 18

Standalone components, lazy-loaded routes, and signals-ready architecture — all prompted into existence.

🟢

Node.js + Express

REST API backend with route handlers, middleware, and SQL integration — generated from a single backend setup prompt.

🗄️

MS SQL Server

Database layer configured and connected via prompted db.js config. Schema and queries described in plain language.

🎨

SCSS + CSS Variables

Dark theme, responsive breakpoints, glassmorphism — all designed via prompt. Zero Figma, zero manual CSS sessions.
